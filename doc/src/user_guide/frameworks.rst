.. _frameworks:

************************************
Frameworks, SQL Generators, and ORMs
************************************

The Thin mode features in the python-oracledb 1.0 release covers the needs of frameworks that depend upon the Python Database API.

The products that will be evaluated for impact by python-oracledb Thick and Thin are:

    - SQLAlchemy (and Pandas)
    - Django

Until SQLAlchemy, Django, or other third-party frameworks and Object-relational Mappers (ORMs) add native support for python-oracledb, you can use one of the solutions detailed in the :ref:`toggling` section.
