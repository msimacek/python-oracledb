.. _sesspool:

************************
API: SessionPool Object
************************

.. note::

    The SessionPool object is deprecated in the python-oracledb 1.0 release
    and will be desupported in a future release. It is recommended to use
    the equivalent :ref:`ConnectionPool Object <connpool>` instead.

    Connection pooling in python-oracledb is handled by ConnectionPool objects.
    See :ref:`connpooling` for information on connection pooling.
